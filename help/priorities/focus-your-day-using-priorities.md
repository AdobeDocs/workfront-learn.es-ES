# Enfoque su día usando prioridades

Las prioridades de Workfront actúan como su centro de control personal para administrar las tareas y los problemas que se le han asignado directamente. Consolida el trabajo de varios proyectos en una sola vista centrada, lo que le ayuda a priorizar las tareas de forma eficaz.

>[!VIDEO](https://video.tv.adobe.com/v/3502459/?learn=on&enablevpops)

Cuando utilice Prioridades, tenga en cuenta lo siguiente:

1. Muestra el trabajo asignado directamente a usted, no las tareas asignadas a equipos u otros usuarios.
2. Las tareas de los proyectos con un estado actual o equivalente aparecen aquí.
3. Esta herramienta es para organización personal y no modifica los planes de proyecto compartidos ni las prioridades del equipo.

## Funciones principales

1. **Lista de trabajos y filtros**
Utilice filtros integrados, como el filtro &quot;Listo para comenzar&quot;, para centrarse en las tareas que están disponibles ahora o que aparecerán pronto. También puede utilizar filtros inteligentes para aplicar consultas de lenguaje natural, como &quot;mostrarme tareas vencidas en el proyecto X&quot;.

2. **Mi enfoque**
Mi enfoque le permite establecer prioridades personales para las tareas sin alterar los datos oficiales del proyecto. Por ejemplo, marque una tarea como urgente para satisfacer necesidades inmediatas y, al mismo tiempo, mantener la prioridad general del proyecto.

## Sugerencias diarias de flujo de trabajo

1. Al final del día, revise las tareas completadas, actualice los cambios y restablezca Mi enfoque para el día siguiente.
2. Comience cada día marcando Prioridades para centrarse en los elementos de trabajo más importantes.

Al utilizar Prioridades y Mi enfoque, puede optimizar su flujo de trabajo diario y garantizar que las tareas críticas se aborden a tiempo.
