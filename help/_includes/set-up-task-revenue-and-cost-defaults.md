# Configurar valores predeterminados de ingresos y costos de tareas - COMPARTIDO

Descubra dónde se utilizan el tipo de ingresos y los tipos de costes, y cómo configurar los valores predeterminados del sistema.

>[!VIDEO](https://video.tv.adobe.com/v/3484183/?captions=spa&quality=12&learn=on&enablevpops=1)

## Principales conclusiones

* **Visualización de datos de costos e ingresos:** Se puede acceder a los detalles de costos e ingresos de las tareas si se abre la tarea, se seleccionan los detalles de la tarea y se desplaza a la sección finanzas. &#x200B;
* **Valores predeterminados para las tareas:** Los administradores del sistema pueden establecer tipos de costo e ingresos predeterminados para los jefes de proyecto si navegan a &quot;Configuración > Preferencias del proyecto > Tareas y problemas&quot;. &#x200B;
* **Valor predeterminado de tipo de ingresos comunes:** &quot;Rol por hora&quot; es un valor predeterminado típico del tipo de ingresos, lo que permite registrar el tiempo registrado como potencialmente facturable si el usuario tiene un rol con una tasa de ingresos. &#x200B;
* **Valor predeterminado de tipo de costo común:** &quot;Usuario por hora&quot; se usa a menudo como tipo de costo predeterminado y extrae los datos de costo directamente del perfil del usuario para realizar un seguimiento eficaz. &#x200B;
